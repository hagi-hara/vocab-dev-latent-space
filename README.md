# Shared structure and variation across populations, individuals and time in early vocabulary development: A data-driven latent-space approach

**Authors:** Anonymous

## Overview

This repository contains the primary data and code used in the following manuscript:

*Shared structure and variation across populations, individuals and time in early vocabulary development: A data-driven latent-space approach*

The analyses were conducted using **Python**, **Mathematica**, and **R**. The repository includes the code and data necessary to reproduce the main analyses and figures reported in the manuscript.


## Data availability

Most of the data used in this study are provided in this repository or are publicly available from the original sources described in the manuscript.

Large data files are hosted separately on [Google Drive](https://drive.google.com/drive/folders/1T-tkXZlCKT0Fohw-rrfFIVHSlWOefk3I?usp=sharing). Please download the required files and place them in the corresponding folders in this repository as needed.

Data obtained through **Databrary** cannot be redistributed through this repository because of access restrictions. Researchers wishing to use these data should obtain access directly through Databrary and the relevant dataset.


## Code

The repository contains code for:

- VAE modeling and latent-space construction
- Analysis and sampling of the latent space
- Statistical analyses and visualization

Further details on the analyses are provided in the Methods section of the manuscript.
